# Contribution and provenance

## Hackathon work

SEALED was developed for the Meta Global AI Developer Hackathon in October-November 2026. The game implementation, deterministic engine, Vue interface, Node/SQLite server, Meta preparation integration, content checks, prepared demo entry and demonstration video were created during this project. No pre-existing commercial application is presented as newly built. Development used coding assistance; this is not a claim that Meta's coding agent wrote the source.

The initial design work preceded the participant guide's stated October 27-November 4 building period. The public entry and video show the later adventure reader and preparation integration developed during that period. Retained earlier prototypes are identified separately and are not presented as fresh live generation.

The public repository is a clean delivery snapshot, not a backdated development history. Private commits and operational evidence remain in the original local project. The publication date is not the date each source line was authored.
